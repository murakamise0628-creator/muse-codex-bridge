# Muse × Codex 連携の型

GitHubリポジトリを共有の作業場にして、Muse（調整・監査）とCodex（PC側の実行）が分担するための決め事。

## 役割

- **村上さん**：案件の精査（承認）と最終判断。やることは「どの案件を回すか決める」「Codexにリポジトリを開かせる（初回だけ）」「送信・公開・支払いの承認」だけ。
- **Muse**：調査、指示書（TASK.md）を書く、成果物の監査（REVIEW.md）、次の指示を書く、継続運用（定期チェックなど）。
- **Codex**：TASK.mdを読んでPC側で実行し、成果物を work/ に置く。進捗はTASK.md末尾の進捗メモに追記する。

## 流れ

1. MuseがTASK.mdにタスクを書く（目的・成果物・条件・完了の定義まで具体的に）。
2. CodexがTASK.mdを読んで作業し、成果物を work/ に置き、進捗メモに「やったこと・残り」を書く。
3. Museが成果物を確認し、REVIEW.mdに判定（OK／直し）と指摘を書く。
4. 直しがあればTASK.mdに次の指示を追記して2へ。OKなら完了。

## ルール

- 送信・公開・応募・支払いは、村上さんの承認なしに実行しない（どちらのAIも）。
- 個人情報（住所・電話・メール本文など）はこのリポジトリに置かない。
- ファイルの置き場所：指示はTASK.md、監査はREVIEW.md、成果物は work/、それ以外は置かない。
- コミットメッセージは短く日本語で（例：「TASK追加：〇〇」「成果物：〇〇初版」「監査：直し2点」）。
- 判断に迷う仕様は、勝手に決めずTASK.mdの進捗メモに質問として書き、村上さんかMuseの判断を待つ。

## 始め方（村上さんの初回作業）

1. このリポジトリをPCにcloneする。
2. Codexでこのフォルダを開き、CODEX.md を読ませる（最初の指示は「CODEX.mdとTASK.mdを読んで、その通りに進めて」でよい）。
